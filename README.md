# Akev Homebrew tap

Homebrew packages for [Akev](https://akev.dev), the open-source HTTP(S) debugging proxy.

## Install

Command-line tool (macOS and Linux; starts the proxy and opens the web UI):

```sh
brew install akevdev/tap/akev
```

Desktop app (macOS):

```sh
brew install --cask akevdev/tap/akev-desktop
```

Then run `akev`, or open Akev from Applications.

## Update

```sh
brew update && brew upgrade akev
```

The desktop app updates itself after you confirm.

## About this tap

The formula and cask are generated by Akev's release workflow
([`packaging/homebrew`](https://github.com/akevdev/akev)) and copied here automatically for
each release after their checksums are verified against the release's signed `SHA256SUMS`.
Every change is tested on macOS (Apple silicon and Intel) and Linux (x86_64 and arm64).

Issues: <https://github.com/akevdev/akev/issues>
